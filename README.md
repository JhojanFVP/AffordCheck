## Option B: Real email signup ready for Supabase

The email form now works two ways:

1. If Supabase environment variables are missing, it saves test signups in browser localStorage.
2. If Supabase environment variables are present, it sends signups to a Supabase table named `signups`.

## Supabase setup

In Supabase, create a table using this SQL:

```sql
create table public.signups (
  id bigint generated by default as identity primary key,
  email text not null,
  source text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

alter table public.signups enable row level security;

create policy "Allow public signup inserts"
on public.signups
for insert
to anon
with check (true);
```

## Vercel environment variables

In Vercel, go to:

Project Settings -> Environment Variables

Add:

```text
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Then redeploy.
